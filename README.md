# 🎟️ LottoWebApp

Веб-приложение для статистического анализа и визуализации результатов лотерейных тиражей. Автоматизирует ручной анализ, представляя данные в различных проекциях для глубокой и наглядной интерпретации.

## 🚀 Ключевые возможности
- **Сбор данных**: Автоматическая загрузка и хранение истории тиражей из официальных источников.
- **Высокая производительность**: Оптимизированные алгоритмы для стабильной обработки больших объемов исторических данных.
- **Гибкость**: Ролевая модель (пользователь/администратор), гибкая фильтрация, сортировка и экспорт результатов в различные форматы.

## 📊 Функционал и алгоритмы анализа
Ядро приложения разделено на 6 логических групп алгоритмов:

1. **Общие характеристики**  
   Статистика тиражей, топ-10 частых и редких чисел (с группировкой по дням недели, месяцам, годам и позициям), анализ частоты и шансов выпадения дополнительных шаров.
2. **Частотный анализ**  
   Расчет общей частоты (за 10, 50, 100 тиражей), выявление наиболее частых чисел и построение карт пауз.
3. **Табличные карты**  
   Визуализация распределения: четности/нечетности, сумм, медианы, дисперсии, мин/макс, простых/составных, высоких/низких и специфических чисел (треугольных, квадратных, зеркальных). Анализ комбинаций и разниц между позициями.
4. **Досье**  
   Детальный статистический профиль отдельного числа или числовой комбинации.
5. **Таблицы переходов**  
   Матрицы переходов чисел (исходные и упорядоченные), анализ переходов по интервалам, позициям и номерам шаров.
6. **Поиск фигур**  
   Геометрический анализ игрового поля для выявления горизонтальных, вертикальных и диагональных закономерностей.

## 📈 Визуализация данных
Преобразование табличных результатов в наглядные графики и диаграммы.  
*Особенность:* данные визуализируются в **комбинированных графиках**, позволяющих одновременно анализировать частые и редкие числа в едином представлении, что ускоряет интерпретацию.

## 🛠 Стек технологий
- **Backend**: C# (ASP.NET Core)
- **Frontend**: HTML, Razor
- **Аналитика**: Собственные алгоритмы статистического и геометрического анализа

## ⚙️ Запуск проекта
### Требования
- [.NET SDK](https://dotnet.microsoft.com/download)
- Git

### Шаги
bash
git clone https://github.com/Kolugin/LottoWebApp.git
cd LottoWebApp
dotnet restore
dotnet run --project LottoWebApp
*Откройте локальный адрес (например, `https://localhost:xxxx`), указанный в консоли после запуска.*
