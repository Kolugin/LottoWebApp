# 🎟️ LottoWebApp

Веб-приложение для проведения и управления лотереями на базе .NET.

## 🛠 Стек технологий
- **Backend:** C# (ASP.NET Core)
- **Frontend:** HTML, Razor
- **Архитектура:** Web App

## 🚀 Запуск проекта

### Требования
- [.NET SDK](https://dotnet.microsoft.com/download)
- Git

### Шаги
```bash
git clone https://github.com/Kolugin/LottoWebApp.git
cd LottoWebApp
dotnet restore
dotnet run --project LottoWebApp
